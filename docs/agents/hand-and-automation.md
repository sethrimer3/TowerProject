# The hand, badges, charges and automation

The planners, Tower automation, the hand of cards, card badges, Focus/Ignore/Target charges, Rush, play/pause, and deadlock.

The planners (`routeTo`, Tower automation's search and Delve Automove) work from a `Position` (`board.ts`: a board and the run standing on it), never the whole `Game`.
`chooseStep(game)` in `automation.ts` is the one entry that reads the rest (the mode and Delve Automove's memory, plan and upgrades), and `tests/planners.test.ts` drives the planners on hand-built boards.
Tower automation (`automation.ts`) runs a bounded breadth-first search (`Search`) with separate destination scoring.
It stops searching at interactions and replans every step rather than assuming future keys or health, never takes lethal fights, and scores progress against the run record so it can backtrack without oscillating.
Inside a run (Tower or Delve, not the forest) the player's **hand** moves the hero: `cards.ts` holds the cards (`CARDS`, the new profile's `BASE_HAND` filling the hand's `BASE_HAND_SLOTS`, more with Larger Hand and Gems (`handSlots`), saved as `save.hand`, and `moveCard`, the Deck's reorder) and `planHand`, a pure breadth-first search from the hero over crossable tiles (floor, one-way gates and every item; walls, doors, monsters and stairs only as targets) (of equally short paths, the one stepping on the fewest `takesSomething` tiles, so the hand walks round items and lit torches unless they lie on the only shortest way; Charge's search doesn't) that returns the first card in priority order that can act: one that acts in place (`IN_PLACE`: KEY SIPHON, asked through the `HandAt`'s `canAct`, which `Game` answers; such a plan has no path, and `handTurn` runs it as a turn with no step: `Game.siphon` trades the run's top Max HP training levels, `siphonCost` of them (one more each use: `run.siphoned` counts the uses), out of `siphonLevel`, the hero's ranks plus those bought with Silver less those siphoned, for a yellow key, after an undo snapshot; without enough left the HUD greys the card, `unable`), or one with a reachable target on the current floor only (never through stairs, never down) and the shortest path to its closest one (the Delve's STAIRS card, whose text, `cardText`, says so only once Into the depths is owned, climbs to the highest crossable tile in view instead, only above the highest row the run has reached, `run.top`, so it never leads back to a row stood on before).
A run copies `save.hand` into `run.hand` when it goes inside (`game.hand` reads the run's, or in the forest the saved one), so reordering never reaches a run already inside; `deck.arrange` (`DeckEditor`, `game/deck-editor.ts`, the game's `deck`) reorders `save.hand` only in the forest, once Combat Stance is owned, and `deck.add` and `deck.remove` move the deck's cards (`deckCards(upgrades)`: the base hand's, and each card an upgrade row names with `card`, `upgradeCard`) in and out of it once Buildout is owned; STAIRS never leaves.
**Card badges** (`badges.ts`, opened by the Courage skill **Badges**) are tokens attached to cards: `BADGES` holds each one's rarity, kind (`reward`, `gate`, `aim`, `scale` or `chance`), symbol and values by level, levels come from copies (`COPIES_FOR_LEVEL`: the first copy opens level 1 and counts toward level 2; 80 reach level 7), and `drawBadges` draws by `RARITY_WEIGHTS` among the rarities with a badge left below level 7 (maxed ones leave the pool), continuing the stream saved in `save.badges.rng` (seeded once from `stream("badges")`), so a purchase can't be redrawn by reloading.
`save.badges` also holds the copies and a gate's chosen threshold (`pick`) per badge, and `cards`, which card holds which (one each way: `attachBadge` swaps).
The Deck page's `BadgeDesk` (`game/badge-desk.ts`, the game's `badges`) draws for Gems (`DRAW_GEMS`), attaches, detaches and picks, in the forest only; a run copies its hand's into `run.badges` as it goes inside (`runBadges`).
Inside a run `Game.cardRules` turns each card's badge into the `CardRules` `planHand` takes through `HandAt.cardRules`: a gate's `closed` skips the card (unless it is the focused card, planned with `only`), Stairward's `stairward` picks the target nearest the stairs by walk (the highest in the Delve), Skip Open Nodes' `skipOpen` passes over a door or monster whose open neighbours the hero can all reach already (reporting each into `run.skipped`, which the renderer marks with an X for that floor), and Charge's `charge` searches through up to that many fightable monsters and doors the hero holds keys for (`chargeSearch`).
Stairward and Skip Open Nodes cool down by floor (`run.badgeFloors`, the floor each last worked on).
**Deprioritize**'s `deprioritize` passes over the target the card would pick, marking it ? (`run.marks`, by `badgeFloor`, cleared as its tile is stepped on), and the cards after it plan round it; `HandAt.marked` (the ? tiles, `Game.marked`) keeps every card's search off them, and once its level's marks are made the card rests `closed` for the floor (`Game.cardResting`, which the HUD greys as `unable`).
When no card can act, `handTurn` turns the ? nearest by walk into ! (`raiseBang`) and the card's `bang` heads for it by any path; the renderer draws both marks (`drawBadgeMarks`).
**Effective** and **Dampen** (`scale`) multiply the card's target's effect when it activates: `handTurn` resolves the card's last step with `StepRules.scale` (`scaleOf`: 1.05 … 1.35, or 0.95 … 0.65), so `resolveStep` scales a potion's heal, a key (keys held are fractional, `snap`ped, shown by `keyCount` in `whole.ts` to two decimals when not whole), a shard, each key a door takes (`doorCost(tile, player, scale)` needs that much of each colour held; DOOR's `CardRules.scale` makes the card want only doors it can pay; the door cards want a door run only while the hero can pay for every door of it, `paysRun`), a Heart Door's toll (only ever smaller) and a fight's damage, which the fight plays out as predicted and adds (`StepEffect.extraDamage`, which can fell the hero; given back as a heal below 0) when it settles, with its Silver, Gold and XP (`StepEffect.scale`, through `winFight` and `RunPurse`); KEY SIPHON's key too.
**Skip** (`chance`) rolls on the card's last step, drawing the next number of its own stream, started from the run seed (`Game.skipRoll`; `run.skipRolls` counts those drawn, counted once the step is in the undo history, so undo takes a roll back and a run of the same seed played the same way skips the same targets): the target vanishes without effect (`vanish`, a turn of its own, with `poof.ts`'s puff at `game.vanished`), never a boss or Greater Boss; on the Tower's stairs `advanceTowerRoom` climbs two floors (`floorSkip`; the floor climbed past pays no Spare Change or Wishing Well, and an area climbed past is still judged) with *Floor Skipped*.
It has no limit a floor.
**More Enemies** (`floor`, the one badge that changes the floors themselves, `more-enemies.ts`) sits only on a monster card (`BadgeDef.cards`, `fitsCard`: `attachBadge` refuses another card, a swap that would carry it onto one takes it off, and both decoders drop it there); `extraEnemies(run.badges)` sums each strength's percent over the cards covering it (MONSTER every strength, each from its own count; the Greater Boss never), and the boards add the extras as a last stage before `tierCells`: `RoomWorld` (its `extras`, through `withExtraEnemies`) and the Delve `World` (its second argument, through `delveExtras`, cached per area, each of the area's ten equivalent floors by tile depth counting and placing its own, bottom first, on one `extraGround` for the area: the tiles as a grid of indices with their neighbours and the shortest walk worked out once; the area's torches come from the cache `World.torches` reads too, so they are placed once).
`addEnemies` adds each strength's generated count times its percent, the fraction rolled as a chance of one more, each a copy of one of the floor's own of that strength, placed by `nextSpot`: corners of reward rooms behind a gate (a door or enemy), corners of other rooms behind one, corners and then edges of the core, any tile that cuts nothing off (Tarjan's articulation points, extras already placed counting as walls), and only then one that does, off the shortest walk from the way in to the target (the stairs, or the area's boss) first; never the way in or beside it, beside the stairs, near the milestone gate or on a torch.
All its rolls come from a stream seeded by the run seed and floor (`extrasSeed`), so a floor comes out the same whenever it is rebuilt; runs without it generate exactly as before, so no layout version moves.
`Game.newRun` rebuilds the board after `dealHand` so a run going straight inside gets its extras.
`tests/more-enemies.test.ts` covers it.
Turning on Dev mode (`setDevMode`) owns Combat Stance, Buildout and Badges and every badge at level 7.
`handTurn` activates a card when its path's last step lands (after its fight settles, wrapping the encounter's `settle`) or an in-place card acts: `Game.activate` pays the rewards, HP and Silver and XP through the run (so undo takes them back) and Gold through `RunPurse.badgeGold`, gated per target in `lootedTiles`.
`ui/badge-token.ts` draws the tokens, the marks cards wear for them and each badge's value at every level (`badgeLevelsHtml`, from each `BADGES` entry's `unit` and `lead`, under its description in the Deck page's detail and the draw animations) and `ui/badge-reveal.ts` the draw animations.
**Max HP** raises the hero's max HP (and `run.loadout`'s) and its HP by the badge's value for the rest of the run.
**Goldback** (last card of the hand; it raises *×2* beside the Gold coin) adds its value to `run.goldCombo`, which the next kill's or chest's Gold multiplies by and spends (`RunPurse.withCombo`, once the Gold is actually paid; the combo is the run's, so undo takes an activation back).
The Badges draw screens offer `DrawAgain` ("x1 more" / "x10 more" with the Gem price, its price red (`short`) while unaffordable, and a press then asks for Gems) on their last screen.
`tests/badges.test.ts` covers it.
The run also gets `FOCUS_PER_RUN` Focus uses (`run.focusUsed` counts those spent, so a Focus Count level completed mid-run adds one at once) once the Focus skill is owned: `Game.focus(card)` spends one to put that card first (`run.focused`; refused, with a reason the HUD flashes, when none are left, the card leads already, or `planHand(…, only)` finds it no path), and `handTurn` plans the focused card alone until its path's last step or until it has none.
Both live in the run, so undo and reloads keep them.
Focus, **Ignore** and **Target** are the run's **charges** (`run-charges.ts`): each opens with its Courage skill, starts a run with its research's count (`chargesPerRun`: Focus Count, Ignore Count, Target Count), keeps only the uses spent in the run (`focusUsed`, `ignoreUsed`, `targetUsed`), and, once its regain skill is owned (Refocus, Ignore More, Target More), regains one every `regainEvery` new floors climbed (`REGAIN_FLOORS`, 100, less a floor a level of its research), `climbFloor` counting each floor new to the run into `run.regain` while the charge is below full (`Game.regainCharges`, from `advanceTowerRoom` and `payDelveFloors`).
`Game.arm` readies Ignore or Target from its HUD button (`game.armed`, never saved), and the next board tap goes to `Game.useArmed` instead of the overlay: Ignore marks the tile in `run.ignored` for the floor (`badgeFloor`), which `HandAt.ignored` keeps every card's path off, `?` and `!` paths and Charge's included; Target stores the tile in `run.targeted`, and `handTurn` first takes `targetTurn`, a step along `planTarget` (`cards.ts`: the plain search round ignored tiles, the last step onto whatever stands there) until the hero arrives or the tile goes out of reach ("Target lost").
The renderer marks both (`drawChargeMarks`); `tests/run-charges.test.ts` covers them.
`Game.autoTurn` runs it inside a run (`handTurn`: follow the committed `cardPlan` a step at a time, forced, so a lethal fight is taken; plan again once it ends or a step is refused; the first step of a new plan onto empty floor **rushes**, `rushOn`, carrying on along the path in the same turn across up to `game.rushTiles` more empty tiles (nothing on them, no torch, no Gem; `emptyAt`), the later steps untracked so the rush is one undo, and sets `game.rush`, the tiles rushed off, which the renderer snaps the hero past and `rush-echoes.ts` draws as fading echoes of the hero over 0.5 s; `rushTiles` is the Rush research's `rushTiles` target once the Courage skill Rush is owned, read when used; `tests/rush.test.ts` covers it), and Automove only in the forest.
`game.auto` is the hand's play/pause inside a run: on when a run starts or enters, and off after undo (which drops the path; a plain pause keeps it, and the card that led glowing, so playing on follows it) (and from the start in Dev mode, or when a page sets `globalThis.__handStartsPaused`, as the browser UI suite does).
When no card can act, `handStuck` is set and the hand pauses, the HUD shows End Run in red at the foot of the height column as well as in the run's menu, and the run ends only when the player ends it; each player action inside a run (run training, Ignore, and skills to come, through `afterPlayerAction`) checks the hand again and sets it playing once a card can act.
The player can't step or walk inside a run unless Dev mode is on (`game.manualMoves`).
`tests/cards.test.ts` drives `planHand` on hand-built boards, `tests/key-siphon.test.ts` and `tests/inspiration-cards.test.ts` the cards that act in place and the cards below Key Siphon, and `tests/game-commands.test.ts` the hand's turns.
`isDeadlocked` (`analysis.ts`), which searches every visited Tower floor, reading each from the climb, through their stairs, for anything the player could still do, no longer ends runs; `tests/tower-automation.test.ts` still records it.
`tests/tower-automation.test.ts` records the step Automove picks and the deadlock call on every step of seeded runs against `tests/fixtures/tower-automation.golden.json` (regenerate with `UPDATE_GOLDEN=1` only for an intended automation change), and `tests/tower-overhaul.test.ts` pins the deadlock rules on hand-built floors.
