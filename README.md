# Tower Delve

A playable, original mobile-first incremental tower RPG. Canvas draws the dungeon and pixel entities; accessible DOM controls provide navigation, statistics, inspection, and progression. No backend or runtime game engine.

## Run

Use Node.js 22.18+ (tested with 24.15) and npm:

```sh
npm install
npm run dev
npm test
npm run build
npm run preview
```

Open the local URL printed by Vite. In the forest before a run, tap an open tile to walk to it, fighting monsters and collecting items along the route. Swipes move one tile in any cardinal direction. Keyboard arrows / WASD also work; on-screen arrows are off by default and can be enabled in Settings. Monsters on manual routes are fought even when lethal. Missing keys stop movement at the necessary door, with a fading red X; unreachable wall targets get the same feedback at the tapped spot. Routing prefers an available detour over a door for which no key is held.

Inside a Tower or Delve run, your **hand** of cards moves the hero instead; taps only inspect, and swipes and keys do nothing (except in Dev mode, which also starts the hand paused). A new profile's hand is its whole deck, in priority order: **Stairs** (the stairs up; in the Delve, the highest open tile in view), **Door** (a door you hold the keys for), **Yellow Key** (a yellow key, never a blue or red one), and **Monster** (any monster that can be fought, even a lethal one). Three more cards join the deck from the Inspiration tree: **Heal** (a potion; the Heal skill, 3 Inspiration, after Buildout, beside Larger Hand), **Equipment** (an ATK or DEF pickup; the Equipment skill, 5 Inspiration, after Focus) and **Blue Key** (a blue key; the Blue Key skill, 2 Inspiration, after the Archives). Each new card rises from the bottom of the screen to its middle, green rays turning behind it and what it does written below, until you press it. Whenever the hero has no path to follow, the first card that can reach a target over open floor and items picks its closest one, and the hero walks the shortest path there, one step per tick of the movement speed (3 steps a second until **Movement Speed** is owned), taking the items on the way; the card glows as it moves, and keeps glowing while the hand is paused; playing on carries on along the same path. When no card can act, the hand pauses and End Run lights up: the run ends only when you end it. Whatever you do next (using an item, and later a skill) checks the hand again, and it plays on by itself once a card can act. The play/pause button (where Automove was, showing ▶ while paused and ❚❚ while playing) pauses the hand to look around or use an item, and undo pauses it too. The cards sit in the row under the board. Each run keeps the hand as it was ordered when the run went inside, however the hand is rearranged before the next.

Each Inspiration skill that can be bought wears its price in a circle on its corner, filled when the Inspiration is there and outlined when not, so a path's cost shows at a glance. The Inspiration tree's first skill, **Combat Stance** (1 Inspiration), adds a **Deck** tab after Tower and Delve. The Deck page shows the hand's slots along the top: four, five with **Larger Hand** (1 Inspiration, after Buildout), and one more for each slot bought with Gems after that (50, 200, 400, 600, 800 and 1,000 Gems, up to eleven), the next for sale standing after them; dragging a card to another slot (or moving a focused card with the arrow keys) shifts each card in between over one, and the new order is saved at once. Below the hand sits the deck, locked until **Buildout** (1 Inspiration, after Combat Stance): then the deck's cards are laid out on a grid, those in the hand greyed out with a check that returns them to the deck, and pressing any other card adds it to the hand's first empty slot. Dragging one onto a hand slot puts it there instead: with room in the hand, the cards from that slot on slide one slot later; with the hand full, the card in that slot goes back to the deck (never STAIRS). A hand card shows an X in its corner while hovered (always, on touch screens) that also returns it to the deck. A hand must always hold STAIRS, which has no X and can only be reordered; every other card is optional. Every change is saved at once. While a Deck lesson is waiting, its tab carries a red dot. The Upgrades tab carries one too, once the first run that earns Inspiration is over, until you open it, and so does the Gear tab once the Gear skill is bought, until you open it. The first visit teaches the drag: a note explains the order and a hand points at STAIRS, the other cards and tabs stay disabled until STAIRS is moved, and a dialog then praises the new order. With Buildout, the next lesson shows the X on MONSTER with a hand pointing at it, and again nothing else can be used until it is pressed; a dialog praises that (closed by pressing anywhere on it), and a note over the deck, dismissed by pressing it, explains adding cards.

**Gear** (1 Inspiration, after Buildout, beside Larger Hand) adds the **Gear** tab, which opens on **Provisions**: Gold buys a Traveler's elixir (+20 max HP), an Aegis charm (+1 DEF) or a Whetstone (+1 ATK), each kept for good and added to every run from then on, a run already inside included. Each one bought costs more than the last, on the same kind of schedule as Training bought with Silver inside a run (the elixir from 5 Gold, the charm from 10, the whetstone from 15). Once **Extra Key** (1 Courage, after Movement Speed in the Courage tree) is owned, Provisions also sell a **Yellow Key**, a yellow key carried into every run: the first costs 100 Gold and each after four times the last (400, 1,600, 6,400, 25,600 …). The Equipped, Inventory and Crafting tabs stay closed for now.

**Focus** (5 Inspiration, after Larger Hand) is the player's own say in where the hero goes inside a run. Pressing a card in the hand under the board puts it ahead of the others: it glows white, the hand plays on (even if it was paused), and the card leads until the hero reaches its target, or until it has no path to one, when the hand's order leads again. Each run starts with 1 Focus, shown by a lightning bolt beside the potions in the stats, and each Focus that takes spends one; a Focus Count level completed during a run adds its use at once. With none left, the bolt flashes red; a card with no path to a target flashes red and costs nothing; the card already moving the hero can't be focused. Undo brings back the Focus uses and focused card of the moment they return to.

The Upgrades page shows a tab only once what unlocks it is owned: Inspiration from the start, then Training, Courage (with Into the depths), the Archives, Wayfinding (with Movement Speed), and Legacy, Wisdom and Renown (with An enduring legacy); Dev mode shows them all.

**Archives** (10 Inspiration, after Focus) adds an Archives tab to the Upgrades page, before Wayfinding: research that lasts between runs, paid in Gold and real time. An archivist works on one project at a time, a level at a time: pay the level's Gold, and it completes on the clock, whether the game is open, on another page, or closed. You start with one archivist and can hire up to four more for Gold. Stopping research gives its Gold back and keeps the time already spent for when you start it again (paying again). With **Auto-continue** ticked, an archivist starts the project's next level as soon as one completes, if you have the Gold; otherwise it waits idle. Each level completed pops up at the top of the screen, over everything, as "Research Complete!" with the project and level, for four seconds before it slides up out of sight; levels that complete together (such as while the game was closed) follow one another in order. The library can be searched and filtered by category and status, and a history lists each completed level. The first project, **Focus Count** (after the Focus skill), adds one Focus use to every run for each of its nine levels: level 1 takes 8 hours and costs 500 Gold, each level after takes 8 hours more, and costs 500 Gold times the level before it more (500, 1000, 2000, 3500, … 18,500). Below the Archives in the Inspiration tree, which grows taller than the screen and scrolls (drag it, or turn the mouse wheel; Ctrl and the wheel, or a pinch, zooms), **Greater Heal** (3 Inspiration) opens the Archives' **Potion HP** research,, **Recovery** (10 Inspiration, after Greater Heal) brings **percent potions** onto the floors (2% of potions), **Find Potion** (10 Inspiration, below Recovery) opens **Find Potion** training, which makes more of them percent potions, and **Shroud** (10 Inspiration, after Greater Heal, beside Recovery) wraps the hero in a **shroud** that blocks the first 1 damage of every fight and opens **Shroud** training, and **Revive** (10 Inspiration, below Shroud) may raise a felled hero at full HP (see below). **Spare Change** (3 Inspiration, below the Archives, beside Greater Heal) makes every floor climbed for the first time in a run pay Gold: in the Tower each staircase taken up for the first time that run, in the Delve each new ten depth. It pays 3 Gold, and 2 more for each rank of the **Gold / Floor** training it opens (Utility, 1 training point a rank, or Silver inside a run), times the tower's Gold bonus; undo never makes a floor pay twice. It also opens the Archives' **Gold / Floor** research (listed last), +5% of that Gold a level for 100 levels, priced and timed like Potion HP. Below it, three more skills (2 Inspiration each) each open a Utility training row (1 point a rank, or Silver inside a run) and Archives research of the same name (100 levels, priced and timed like Gold / Floor): **Wealthy** opens **Silver Bonus**, which multiplies all Silver a run finds (×1, +3% a rank, and +3% a research level, the two multiplied: 30% of each makes ×1.69); **Loot** opens **Gold / Kill**, which multiplies each kill's Gold the same way, before the tower's Gold bonus; **Wishing Well** opens **Silver / Floor**: every floor climbed for the first time in a run (above the run's highest, in the Tower) pays 3 Silver, and 3 more a rank, +5% a research level, then Silver Bonus. Silver keeps its fractions, like Gold, and the purse shows it rounded down. The shroud is whole again at the start of each fight and takes the enemy's strikes until it is spent; only then does HP fall. What it blocks rises off the hero in silver, beside the red of any damage that got through, the HUD shows it beside DEF once owned, and every damage forecast (the inspect box, route totals, the hand and Automove) counts it. Without Recovery every potion is a regular one; with it, the red, striped potions the Tower's floors roll (half of them) and half of the Delve's corridor-guard potions become percent potions, from the next run on: each restores the regular 35 HP plus 1% of max HP, and 0.25% more for each rank of **Potion %** training. **Potion HP** (listed first in the Archives) makes every potion restore 3% more HP a level, for 100 levels (up to four times as much), the Cinder Tonic included but not the red potion; each level counts the moment it completes, even mid-run. The first four levels are quick (15 seconds for 10 Gold, 1 minute for 25, 5 minutes for 50, 10 minutes for 75); then the formula starts over, so the m-th level after those takes m/4 hours and costs 100 × m Gold (15 minutes and 100 Gold at level 5, up to 24 hours and 9,600 Gold at level 100).

Fights loosen the classic Magic Tower rule that DEF equal to a monster's ATK makes it harmless: after every round of a fight the monster's ATK rises by 1% (rounded down), and by at least 1. High DEF still holds a monster off for a while, but never forever, and a fight with a monster the hero can barely scratch grows lethal instead of dragging on. The inspect panel's damage already counts the rise.

With **Animate fights** on (the default; turn it off in Settings to settle fights at once), stepping into a monster plays the fight out: the hero waits on its own tile and strikes first, the monster strikes back, and each strike's damage rises in red off whoever was struck (a darker red off the hero) while HP counts down in the stats. The HP the fight has cost so far shows in purple on the HP bar, just past the HP left, and shrinks away over a second once the fight is over. A health potion, picked up or crafted and drunk, does the opposite: the HP it heals shows in light red past the HP you had, the red bar fills up over it in a second, and the HP actually healed rises in green over the hero. The first round's strikes take 0.25 s each, and each later round runs at 90% of the one before, down to 0.05 s a strike. Once the monster falls the hero steps onto its tile. Either way, every reward picked up (an item, a chest's Gold and materials, a monster's drops) rises from its tile as its sprite for about a second, starting at once over anything still rising (what comes together, like a chest's Gold and materials, one after another); rewards with no sprite rise as "+N" text. A door raises each key it took with a minus sign, and a Heart Door a heart with a check. Taking the stairs snaps the hero straight onto the new floor with a brief white glow behind it, and while the hero stands on the board's bottom row the status line over it turns half see-through. Undo during a fight takes back the whole fight. Every monster beaten pays Gold by its strength: none for a weak one, 1 for a normal one, 2 for a strong one, 4 for an elite one and 5 for a boss. A boss, glowing red and gold with three chevrons and twice a strong monster's HP and ATK, guards the way up every ten floors: it stands in front of the stairs on Tower floors 10, 20, 30 and so on, and in the shaft below each Delve milestone gate, so it must be beaten to climb on. On other Tower floors the stairs may stand open, behind a monster, or behind a yellow door. In Tower I and Delve I, blue keys and blue doors first appear on floor 20 (the Delve's equivalent floor 20, depth 190) and red ones on floor 50; Tower II, Delve II and the rest have them from their first floors, since a hero who reaches them has met them already. The first floor's stairs can always be reached without a fight, so the starting hand's Stairs card climbs straight to floor 2 (and its Inspiration); floors 2 to 5 always have a yellow door in front of the stairs, a yellow key lying free near the entrance, and a key behind every door, so the starting hand can open its way up. No monster on floors 1 to 10 can beat a new hero (100 HP, 12 ATK) in a single fight, and none of them is an elite from the next zone, but the floor 10 boss can. The stats show the Gold found so far this run beside ATK and DEF; undo never takes Gold back, so it never lowers the count.

Every monster beaten also pays **Silver**, a currency that lasts only for the run, spent on training for that run. A weak monster pays 1 Silver on floors 1–10, 2 on floors 11–20, and 1 more every ten floors after (the Delve counts every ten depth as a floor); a normal monster pays twice that, a strong one three times, an elite four times, and a boss five times. The stats show it beside the Gold. Undo takes back the Silver of the kills it undoes, and a new run starts with none.

**Training for the run.** Inside a run, a bar under the hand holds a wide button for each Training group: Offense, Defense and Utility (greyed until something in it is unlocked). Pressing one shows that group's Training rows in the hand's place, a card each, scrolled sideways: its name, where it stands now (the hero's stat, the percentage, or the Gold a new floor pays), and a button with the Silver price of the next level. Pressing the button pays the Silver and raises it at once, for the rest of this run only (more max HP comes with the HP to fill it); while the Silver isn't there the button's outline and face fade, its price still clear, and the card stays readable (it greys out only at its most). Pressing a card, or hovering over it, shows its description and its level of the most it can reach. The cards are exactly as tall as the hand's, so nothing else on the screen moves as they swap. Pressing the group's button again brings the hand back. A run starts at the hero's own Training level, so more Training between runs lets a run reach higher for the same Silver: the first level bought costs 3 Silver for max HP, 5 for ATK and DEF, 10 for Shroud, Potion % and the currency rows (Gold / Floor, Silver / Floor, Silver Bonus, Gold / Kill), and 20 for Find Potion and Revive. Each level after costs more than the last by a step plus the levels already bought, the step growing every five levels: +1, +3, +5 … for max HP (3, 5, 8, 12, 17, 23, 32 …), +1, +4, +7 … for the 5-Silver rows (ATK: 5, 7, 10, 14, 19, 25, 35 … 85 for the 11th), +2, +5, +8 … for the 10-Silver rows, and +4, +8, +12 … for the 20-Silver rows. A row goes no higher than its most on the Training tab (72 for Find Potion, 99 for Revive), or level 1,000. Each purchase is a turn of its own: undo takes it back, Silver and all.

Every monster defeated pays XP, more for stronger monsters and higher floors, and XP carries over between runs. Each level needs more XP than the last (with the cube of the level), faster than the XP a kill rises with height, so levels come more slowly the higher you climb, even replaying the floors below. The level shows as a large number at the front of the XP bar under the hero's portrait, which fills with the current level's progress; hovering it shows the XP gained toward the next level and what that level needs. Reaching a new level bursts fire outward from the hero, surrounds the hero with a glow for two seconds (fading over the last half second), and flashes "LEVEL UP!" over the board; once it fades, "+3" and the training points' golden arrow rise off the hero. Each level earns 3 **training points**, spent on the Upgrades page's Training tab, which shows once the **Training** skill (2 Inspiration, after Larger Hand) is owned: a table in three groups, Offense (ATK), Defense (max HP, DEF, then Shroud, Potion %, Find Potion and Revive once the Shroud, Recovery, Find Potion and Revive skills are owned) and Utility (Gold / Floor, Silver / Floor, Silver Bonus and Gold / Kill once their skills are owned), each row with what a rank is worth now, its current value, the value one more rank makes it, and two ways to buy the next rank: training points (the arrow button) buy it at once, 1 point for a rank of max HP, Shroud, Potion %, Find Potion or Revive, 2 for DEF and 3 for ATK; or Gold (the coin button) pays a **trainer** to train it, which takes time but no points, at 20 Gold for each point the rank would cost times the rank's number (20 for the first rank of max HP, 200 for its tenth, 60 for ATK's first). A rank in a trainer's hands can still be bought with points too. Potion % adds 0.25% of max HP to what a percent potion restores, and Find Potion 0.25% to the chance that a potion is a percent potion (from 2% up to 20%, at 72 ranks), both the same at every level. A rank grows as the hero levels up, every rank already bought included: at level L a rank of max HP is worth 10 + L, of ATK 1 + L/5, of DEF 1 + L/12 and of Shroud 1 + L/10, fractions and all. A new hero starts with 100 max HP, no DEF and no shroud. Training applies at once to a run still in the forest. A stat can be reset for 2 Gems (its row's reset button), returning every point and all the Gold spent on it, and the time its trainers spent as **time credit**, shown beside a clock under the boost while there is any: the next ranks trainers train start that far along, until it is used up. A trainer's rank takes time, on the clock like the Archives' research: a stat's first four ranks take 15 seconds, 1 minute, 5 minutes and 10 minutes, and each after a quarter hour more than the last (15 minutes, 30, 45 …, 24 hours by the 100th), less with Faster Trainers research. One stat trains at a time, with one more for each trainer bought with Gems beside the trainer count (100, 300, 700, 1,200 and 1,800 Gems, up to six at once). A rank in training shows its countdown (press it to stop, get the Gold back and keep the time spent as credit) and a Gem button that finishes it at once: 1 Gem for each 10 minutes left, and 1 more for any part of 10 minutes. Each rank a trainer finishes, whatever page shows or while the game was closed, announces "Training Complete!" at the top of the screen and counts at once, a run inside included. The box at the top of the tab is the **training boost**: "×2" with its time left, or "Inactive", and an ad button, "+1h" (no ad plays yet: it is granted on the press), each press banking an hour more, up to four. While it lasts, ranks in training go twice as fast, their countdowns dropping two seconds a second, on the clock like the rest. **Faster Trainers** (2 Inspiration, after the Archives, beside Blue Key) opens Faster Trainers research: +2% training speed a level for 100 levels (+200%, a rank then taking a third of its time), the n-th level costing 250 × n Gold and taking 1.75 × n hours, about a year in all.

Movement transitions can be set to **Smooth** (default), **Fast**, or **Off (instant)** in Settings. This controls camera and player interpolation on both axes; Reduce motion overrides it with instant movement.

Matching open left/right world edges wrap to each other. Locked doors and enemies at the destination still apply. Openings have no solid frame across them and show continuation chevrons. Viewport cropping is not a wrap boundary; the world is 30 tiles wide. Vertical movement remains continuous upward.

**Undo** restores one move (a tapped route counts as a single move), including combat, pickups, gear, keys, doors, height, and the XP a kill paid (with any level it reached). It cancels any queued route. A new profile has no undo, and the button stays hidden until **Rehearsed steps** (10 Inspiration, after Focus) gives the first history slot; four levels of **Echoes of time** (Courage) add one each, and so does each of nine levels of **Undo Count** research in the Archives, which Rehearsed steps opens, up to 14 moves. Each counts the moment it's bought or completed. History persists across refreshes.

Every way a run ends goes through one dialog, which says what brought it up and shows the same totals of what the run obtained: the floor reached, the run's highest floor, and the Gold, the Inspiration (or Courage) and the XP earned in this run, the first two with their icons, not the amounts held (undo takes a kill's XP back from it, as from the hero). Pressing End Run asks whether to end the run (or, when no card in the hand can act, says so first), with **End run** and **Keep climbing** (Keep delving). When the hero falls in a fight, the run waits at 0 HP with the hand paused, and the dialog, headed **Fallen in combat**, names the monster. It must be answered: **Undo** (once Rehearsed steps has unlocked undo, while undo moves remain; without it the dialog doesn't mention undo) spends one to take the fight back and leaves the hand paused; **Accept defeat** ends the run, pays what it still owes, and returns to the forest for the next run. The dialog comes back after a refresh until it is answered. Rewards are credited as they are earned and never rolled back, so taking a fight back cannot duplicate them. Ending a run with End Run (or retiring from Settings) goes straight back to the forest once confirmed. Gold is banked the moment it is found and kept however the run ends: the stats show the Gold held, and the run's end dialog and the message after the run say how much the run found.

**Gems** are the premium currency, kept between runs like Gold. The stats show the height alone in their right-hand column, with the Inspiration or Courage a new best would pay under it, and below that the currencies held, one a line: Gems, Gold and the run's Silver (amounts over 9,999 shortened, such as 123K; the exact amount on hover). A Gem now and then lies on a floor: on the next new floor a run reaches (a Tower floor not reached before in that run, or each 10 depth of the Delve, within view ahead of the hero), on a plain tile the hero can walk to, out of the way where there is one (off the routes between the hero and the floor's items, monsters, doors and stairs, tucked into a corner or nook), so the hand's cards seldom walk the hero over it, shining over the darkness. Stepping on it, or tapping it anywhere on the board, collects it in a sparkle for 1 Gem, and the next can't appear for 30 minutes (on the real clock). A Gem left on a floor the hero leaves, or in a run that ends, is gone, and another appears 3 new floors later, again and again until one is collected (that count carries into the next run). Undo never brings a collected Gem back or takes one away. Inside a run, where Floors stands in the forest, a Gem button offers **7 Gems** (for watching an ad, once ads are hooked up; for now pressing it pays them); it hides once claimed and comes back 10 minutes later. Gems buy hand slots (with Larger Hand) and Training resets: each Training row has a reset button that asks to spend 2 Gems to reset that stat to no ranks, saying how many training points it returns, and allows it only when the Gems are there. A Shop page, with free Gems once a day (the day turning at 00:00 GMT) and Gems for real money, is still to come.

**Fractions.** Gold, HP and the hero's and monsters' stats keep their fractions in play: a 2% ATK bonus on 1 ATK strikes for 1.02, a monster in a higher tower can pay 3.1 Gold, and potion healing raised by research keeps its half points. The screen shows whole numbers: Gold and the hero's stats rounded down, each strike, heal and reward to the nearest whole, and a monster's stats to two decimals when they aren't whole.

**Higher towers.** Beating the boss on floor 100 opens **Tower II**, and beating floor 100's boss there opens Tower III, up to Tower IX; the Delve's boss at depth 1,000 opens Delve II the same way. Each one's monsters have three times the HP, ATK and DEF of the one before (Tower II's are 3 times Tower I's, Tower III's 9 times), so a hero needs about three times the ATK, DEF and HP to climb as far, and each pays more Gold and XP: ×2 in Tower II, ×3.1 in III, ×4.3 in IV, then ×5.6, ×7, ×8.5, ×10.1 and ×11.8 in IX. Silver stays the same, so a run buys about the same run training, while potions and ATK/DEF pickups stay the same too (only upgrades will raise those). The floors are laid out as in Tower I, but with blue and red keys and doors from the first floor. Once a second one is open, arrows on either side of the board in the forest choose which the next run enters; its numeral glows over the doorway, and the board's subtitle names it with its Gold & XP bonus. Each keeps its own records: its highest floor, the Inspiration or Courage its new floors pay (again from its first floor), its floor-clear chests and its starting sections.

**Revive** (10 Inspiration, below Shroud) gives each monster's strike that would fell the hero a 0.5% chance to raise it at full HP instead, in a smaller golden blaze like a level-up's: the fight goes on from the next round, the monster as hurt and as fierce as it was, and a later strike that would fell the hero again rolls again. It opens Revive training, 1 training point a rank, each adding 0.5%, up to 50% at 99 ranks. Each strike's roll is fixed for that run, floor and tile, so undoing a fight and fighting it again ends the same way. Forecasts, Automove and the hand still treat such a fight as lost.

Rewards are credited as you climb (Courage for every 10 Delve height, Inspiration for each new Tower floor and floor clear; past floor 100, or depth 1,000, a point of either takes 10 floors, past floor 1,000 100 floors, and past floor 10,000 they stop), so retiring from Settings simply starts a fresh run. A run still in the forest takes everything bought there at once (skills, training, gear, provisions and research); skills bought while another run is inside apply to that run from its next ascent; Wayfinder, Revive, and undo-capacity upgrades unlock immediately. In the forest, Automove still avoids lethal fights; it and the hand pause off the board, in dialogs, and when hidden. No offline progress is calculated.

Inside a run, the row of tabs at the bottom (Tower, Delve, Deck, Defend, Gear, Upgrades, Settings) is hidden and its space left empty: modes, gear and upgrades are chosen in the forest before a run, and a run ends back there. The Settings button in the stats opens the Settings page at any time, with a Back button to the board. Once **Movement Speed** (the Courage tree's first skill, 1 Courage) is owned, the page holds **Movement speed**, the steps a second the hand and Automove take: 1, 2 or 3 (3 until then), and the Archives' **Movement Speed** research (after it; six levels, priced and timed like Focus Count's first six: 500 Gold and 8 hours, up to 8,000 Gold and 48 hours) adds 4, then 5, up to 9. Beside Dev mode, **Dev: free purchases** is a lighter tool for testing: it unlocks nothing, but every purchase (skills, Training, provisions, crafting, research and archivists, Defend) goes through whatever you have and costs nothing, and research completes the moment it starts. The button beside Settings is **Enter** in the forest, an arrow going into an arch: one press goes straight in through the entrance and starts the run. Inside a run it plays and pauses the hand.


## How it's built

Three modes share one page: **Tower** (compact 17 × 17 puzzle floors, generated strategy-first like a Magic Tower), **Delve** (one endless, wrapping labyrinth), and **Defend** (a city-defense simulation). Worlds are generated deterministically from the run seed, and only your changes to them are saved. The viewport shows 17 × 17 tiles with the entrance at the bottom center (20 × 20 in the forest outside); in the Delve, terrain below the last milestone gate can't be revisited.

Code lives in `src/`, with the Tower generator and its floors in `src/tower/`, the Delve labyrinth and its board in `src/delve/`, Defend in `src/defend/`, and the pages, HUD and dialogs in `src/ui/`. Design documents are in `docs/`. Architecture notes, generation invariants, and development commands for contributors (human or AI) are in [AGENTS.md](AGENTS.md).

## Browser verification

Start `npm run dev` in another terminal, then run `npm run test:browser`. See [AGENTS.md](AGENTS.md) for browser-channel and screenshot details.

## GitHub Pages

The included `.github/workflows/static.yml` installs dependencies, runs tests and the production build, then deploys **dist/** on pushes to `main` or manual workflow dispatch. In repository Settings → Pages, select **GitHub Actions** as the source. Vite uses relative asset paths for repository subpaths.

## Prototype boundaries

Room variety and balancing are introductory. Locked passages gate both ascent routes and reward branches; enemies inside chambers are often avoidable. Fights play out unless Animate fights is turned off. Automation prioritizes nearby upgrades and safe ascent, rather than globally optimal inventory planning. Very old tower sections cannot be revisited. Unsupported save-format versions reset safely. Layout-version migration retains progression, stats, and inventory, clears old map edits, and relocates the player to their current section entrance. All text uses the bundled variable Cinzel font from `assets/fonts/Cinzel/`; no remote font service is used. Weather is the only sound. The Archives' research is the only progression that runs while the game is closed; there is no cloud save or installable PWA.
